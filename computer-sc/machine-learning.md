# Machine Learning

## Definition
Machine learning is a field of computer science in which systems learn patterns from data and improve their performance on a task without being explicitly programmed with task-specific rules.

## Key Idea
Instead of hand-coding logic for every scenario, a model is trained on data so it can generalize to new, unseen inputs. Performance typically improves as more relevant data and computation are provided.

## Details

### Types of Learning
- **Supervised Learning** - learns from labeled input-output pairs (e.g., classification, regression).
- **Unsupervised Learning** - finds structure in unlabeled data (e.g., clustering, dimensionality reduction).
- **Reinforcement Learning** - learns via trial and error, guided by rewards from an environment.
- **Self-supervised Learning** - generates its own labels from the structure of the data itself.

### Common Techniques
- Linear/logistic regression, decision trees, and ensemble methods (random forests, gradient boosting).
- Neural networks and deep learning architectures (CNNs, RNNs, transformers).
- Support vector machines and k-nearest neighbors.

## Significance
- Powers modern applications such as image recognition, natural language processing, recommendation systems, and autonomous vehicles.
- Relies heavily on [[optimization|Optimization]] to fit model parameters to data.
- Implemented through [[programming|Programming]], using specialized libraries and frameworks.

## Limitations

### Criticisms
- Requires large amounts of quality data to perform well.
- Models can be opaque ("black boxes"), complicating interpretability.
- Susceptible to bias present in training data, and to overfitting when poorly regularized.

## Related Concepts
- [[optimization|Optimization]] provides the mathematical machinery (e.g., gradient descent) used to train most machine learning models.
- [[programming|Programming]] is the practical medium through which machine learning algorithms are implemented and deployed.
- [[bio-inspired-computing|Bio-inspired Computing]] contributes techniques (e.g., evolutionary algorithms, neural networks) that overlap with machine learning.
