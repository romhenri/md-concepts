# Programming

## Definition
Programming is the process of designing, writing, testing, and maintaining instructions (code) that a computer executes to perform a specific task.

## Key Idea
Programming translates a solution to a problem - expressed as logic, data structures, and control flow - into a form a machine can execute reliably and repeatably.

## Details

### Paradigms
- **Imperative Programming** - explicit step-by-step instructions that change program state (e.g., procedural, object-oriented).
- **Declarative Programming** - describes the desired result rather than the steps to get there (e.g., functional, logic programming).
- **Object-oriented Programming** - organizes code around objects that bundle data and behavior.
- **Functional Programming** - treats computation as the evaluation of pure functions, avoiding shared state and mutable data.

### Core Components
- **Syntax** - the rules governing how valid code is written in a given language.
- **Data Structures** - ways of organizing data (arrays, lists, trees, graphs, hash maps) for efficient access and modification.
- **Algorithms** - step-by-step procedures for solving problems or performing computations.
- **Control Flow** - constructs (conditionals, loops, recursion) that determine the order in which instructions execute.

## Significance
- The practical medium through which [[machine-learning|Machine Learning]] models and [[optimization|Optimization]] algorithms are implemented.
- Enables the realization of [[bio-inspired-computing|Bio-inspired Computing]] techniques as working software systems.
- Underpins virtually all modern software, from operating systems to web applications and embedded devices.

## Limitations

### Criticisms
- Code complexity grows with scale, increasing maintenance cost and the risk of bugs.
- Different paradigms and languages carry trade-offs between performance, readability, and safety.
- Poor programming practices can introduce security vulnerabilities and technical debt.

## Related Concepts
- [[machine-learning|Machine Learning]] and [[optimization|Optimization]] are both implemented through programming languages and frameworks.
- [[bio-inspired-computing|Bio-inspired Computing]] relies on programming to translate biological metaphors into executable algorithms.
