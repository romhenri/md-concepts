# Vector

## Definition
A vector is an ordered collection of scalars, representing a quantity with both magnitude and direction, or more generally an element of a vector space that can be added to other vectors and scaled.

## Key Idea
Where a scalar carries only magnitude, a vector adds structure: an ordered tuple of components, each drawn from the same scalar field, that together specify both size and direction in some space.

## Details

### Representation
- Written as an ordered list of components, e.g. \((x, y, z)\) in three-dimensional space.
- Can represent geometric quantities (displacement, velocity, force) or abstract data (a row of features in a dataset).

### Core Operations
- **Addition** - combining two vectors component-wise.
- **Scalar Multiplication** - scaling every component by a single [[scalar|Scalar]].
- **Dot Product** - combining two vectors into a single scalar, used to measure alignment or compute magnitude.

## Significance
- The fundamental object of vector spaces and linear algebra, built from [[scalar|Scalar]] components.
- A single row or column of a [[matrix|Matrix]], which itself is an ordered collection of vectors.
- Used throughout physics, computer graphics, and machine learning to represent features, positions, and directions.

## Related Concepts
- [[scalar|Scalar]] supplies the components a vector is built from, and the factor by which a vector is scaled.
- [[matrix|Matrix]] generalizes a vector by arranging many vectors into rows and columns.
- [[tensor|Tensor]] treats a vector as a rank-1 tensor, one step above a scalar in the same hierarchy.
